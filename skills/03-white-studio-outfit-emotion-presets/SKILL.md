# 03 — White Studio Outfit Emotion Presets
# 03 — 白色摄影棚穿搭情绪预设图鉴

[中文](#中文) | [English](#english)

---

## 中文

### 1. Skill 功能

这个 Skill 用于生成一套固定风格的**白色摄影棚时尚穿搭情绪图鉴**。

它内置 8 套服装与 8 组对应情绪，并把每套穿搭整理为统一的：

- Front 正面全身
- Side 90°侧面全身
- Back 背面全身
- Headshot 对应情绪面部近景

适合用于：

- 穿搭图鉴
- 角色服装设定
- 三视图参考板
- 表情设定集
- Fashion Lookbook
- Character Sheet
- 图像生成批量提示词

### 2. 触发意图

当用户表达以下或相近意图时触发：

- 白色摄影棚穿搭图鉴
- 这 8 套穿搭做成图鉴
- 三视图 + 表情近景
- 穿搭情绪预设
- white studio outfit board
- fashion emotion sheet
- outfit preset character sheet
- three-view fashion board

只要用户的目标本质上是“**同一成年人物 + 白色摄影棚 + 多套固定穿搭 + Front/Side/Back + 情绪近景**”，即可执行本 Skill。

### 3. 固定人物设定

除非用户明确要求修改，否则固定使用以下人物：

> 明确成年的年轻东亚女性，纤细匀称身材，白皙自然肤色，小巧鹅蛋脸，黑棕色长卷发自然披肩，清透淡妆，保留真实细腻皮肤纹理。

人物必须在所有视角和所有 Look 中保持：

- 同一身份
- 同一脸型
- 同一五官比例
- 同一年龄感
- 同一发色与发型基础
- 同一肤色
- 自然人体比例

### 4. 固定摄影棚与光线

统一采用：

- 白色极简摄影棚背景
- 柔和、均匀、高调光线
- 低阴影干扰
- 真实摄影质感
- 真实服装面料
- 真实皮肤纹理
- 干净时尚图鉴排版

不要擅自加入复杂室内场景、户外背景、家具或无关道具。

### 5. 固定排版

每套 Look 默认生成一张完整图鉴：

**上半部分：**
1. Front — 全身正面
2. Side — 90°侧面
3. Back — 全身背面

**下半部分：**
- 一张对应情绪的 Headshot 面部近景
- Headshot 必须保持同一人物
- Headshot 中能看到与该 Look 一致的领口、肩部或上装关键细节

整体采用 Fashion Lookbook / Outfit Archive / Character Sheet 风格排版。

### 6. 一致性规则

同一套 Look 的四个画面必须保持：

- 同一人物
- 同一发型
- 同一服装
- 同一鞋子
- 同一袜子
- 同一包袋
- 同一配饰
- 同一颜色
- 同一面料

禁止出现：

- 正面与背面服装不一致
- 包袋突然消失或换款
- 鞋型变化
- 袜子长度变化
- 裙长明显变化
- 发型漂移
- Headshot 换成另一套衣服
- 夸张失真的身体比例
- 多余人物
- 截断脚部

### 7. 内置 8 套 Look

#### LOOK 1｜白色不规则吊带 + 牛仔短裤｜傲到抬下巴撇嘴

服装：
白色细肩带不规则吊带上衣，胸前轻微褶皱设计，宽松飘逸下摆，左右不对称尖角衣摆；浅蓝色高腰毛边牛仔短裤，露出自然腰线；灰米色迷你链条斜挎包；白色中筒袜；白色厚底运动鞋。

下巴明显抬高，头部微微后仰，双眼略微向下看人，嘴唇抿起并向下撇，鼻翼轻微收紧，呈现傲娇、不屑、略带看不起人的表情，但保持真人自然质感。

### 8. 执行逻辑

当用户调用本 Skill 时：

1. 默认锁定统一人物设定。
2. 默认锁定白色极简摄影棚和高调柔光。
3. 根据用户指定的 Look 编号选择对应预设；若用户未指定，则输出全部 8 套。
4. 每套 Look 独立生成一条完整提示词。
5. 固定使用 Front + Side + Back + Headshot 结构。
6. 保持所有服装、包袋、鞋袜与人物特征一致。
7. 表情必须转换为明确可视化的眉眼、嘴型、头部与必要手势。
8. 用户若修改某一件服装，只修改对应 Look，不影响其他 Look。
9. 用户若要求更换人物，可替换统一人物设定，但仍保持成年人设定和全套一致性。
10. 除非用户要求解释，否则直接输出可用于生图的提示词。

## English

### Purpose

This Skill generates a consistent **white-studio fashion emotion board** using eight built-in outfit and expression presets.

Each Look is formatted as:

- Front full-body view
- 90° Side full-body view
- Back full-body view
- Matching emotional Headshot

The character, clothing, footwear, bag, accessories, colors, fabrics, hairstyle, and body proportions must remain consistent across all views.

### Default Character

Use a clearly adult young East Asian woman with a slim, balanced figure, fair natural skin, a small oval face, long dark-brown wavy hair, light natural makeup, and realistic skin texture.

### Studio Setup

- minimal white photography studio
- soft, even high-key lighting
- realistic photography
- realistic skin texture
- realistic fabric texture
- clean Fashion Lookbook / Character Sheet layout

### Built-in Looks

1. White asymmetric camisole + denim shorts — chin-up smug expression
2. Pink-gray plaid shirt + black shorts — huge joyful grin
3. Blue-white striped shirt + black mini skirt — tearful downward gaze
4. Gray knit cardigan + denim mini skirt — exaggerated angry O-mouth
5. Black floral square-neck maxi dress — blushing face-covering shyness
6. White sleeveless top + irregular beige skirt — tilted-head skeptical eyebrow raise
7. Light-pink tiered maxi dress — wide-eyed explosive anger
8. Black floral camisole maxi dress — sleepy yawning expression

### Execution Rules

1. Keep one consistent adult character identity.
2. Keep the same white studio and lighting.
3. If a Look number is requested, output that preset only; otherwise output all eight.
4. Generate one complete prompt per Look.
5. Use Front + Side + Back + Headshot composition.
6. Preserve exact outfit, bag, footwear, socks, accessories, colors, and materials.
7. Convert emotions into visible eyebrow, eye, mouth, head-angle, and optional hand actions.
8. If the user edits one Look, do not change the others.
9. If the user replaces the character, keep the replacement clearly adult and consistent across the full set.
10. Return production-ready image prompts without unnecessary explanation unless requested.

### Output Template

```text
## LOOK X | Outfit Name | Emotion

Clearly adult young East Asian woman, slim and balanced proportions, fair natural skin, small oval face, long dark-brown wavy hair worn down, light natural makeup, realistic skin texture. Minimal white photography studio, soft even high-key lighting, realistic fashion photography, clean outfit-board layout.

Top section: three full-body views arranged horizontally — Front, 90° Side, Back. Keep the same character, hairstyle, outfit, shoes, socks, bag, accessories, colors, fabrics, and natural body proportions.

Bottom section: one horizontal Headshot showing the matching emotion while preserving the same character and visible outfit details.

[Outfit]
[Bag / shoes / socks / accessories]
[Headshot emotion]

Clean, realistic, consistent Fashion Lookbook / Character Sheet / Outfit Archive presentation.
```

### Safety

- character must be clearly adult
- keep content within normal fashion, character-design, and emotion-study boundaries
- no explicit sexual content
- no illegal, hateful, or graphic violent content
