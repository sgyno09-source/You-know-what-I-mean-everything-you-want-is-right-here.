这份教程适用于本仓库中的全部 Skill。

你不需要会写代码。核心逻辑很简单：**选一个 Skill → 导入 `SKILL.md` → 提供人物/服装/情绪/参考图 → 让模型按照 Skill 规则生成提示词或视觉方案。**

---

## 1. Skill 是什么？

本仓库里的每个 `SKILL.md` 都可以理解成一套“固定的视觉导演规则”。

普通提示词只描述一张图，而 Skill 会额外规定：

- 什么情况下应该触发
- 人物身份如何保持一致
- 服装、鞋子、配饰如何保持一致
- Front / Side / Back / Headshot 怎么排版
- 表情如何拆解
- 标题、标签、UI、道具如何生成
- 哪些变量可以被替换
- 哪些错误必须避免

因此更适合重复使用、批量生成和长期维护同一种视觉风格。

---

## 2. 最快使用方法

### Step 1｜选择一个 Skill

打开仓库首页，根据你想做的视觉类型选择对应 Skill。

例如：

- 想做人物三视图穿搭图鉴 → `01`
- 想做镜面自拍 Look Book → `02`
- 想直接使用固定白棚穿搭预设 → `03`
- 想做暗黑电影角色档案 → `04`
- 想做 UI × 真人街头创意广告 → `05`
- 想做四栏双语时装目录 → `06`
- 想做婚纱四宫格 Lookbook → `07`

打开对应目录里的 `SKILL.md`。

---

### Step 2｜把 `SKILL.md` 导入你的工作流

在支持自定义 Skill、Agent 指令、系统提示词或长期工作流的工具中，把对应 `SKILL.md` 的完整内容作为规则导入。

如果你的工具不支持 Skill 文件，也可以直接：

1. 打开 `SKILL.md`
2. 复制完整内容
3. 粘贴到模型的自定义指令 / Agent 指令 / System Prompt 区域
4. 再发送你的实际任务

不要只复制某一段示例。完整 Skill 中的一致性、版式、触发和质量控制规则同样重要。

---

### Step 3｜发送你的任务

最简单的输入方式：

```text
使用这个 Skill。

人物：使用我上传的人物参考图，保持脸型、五官、发型、肤色一致。

服装：黑色吊带迷你裙，黑色半透明连裤袜，黑色尖头高跟鞋。

表情：委屈感，眼眶湿润，嘴角轻微向下。

输出：ChatGPT-Image 版完整中文提示词。
```

Skill 会自动按照自身规则补齐构图、光线、排版、一致性和质量控制。

---

## 3. 两种 Skill 类型

### A. 通用生成器

例如 `01`。

这种 Skill 主要提供“规则”，你可以自由换人物、服装和表情。

适合你自己不断添加新 Look。

输入示例：

```text
使用 Skill 01。

统一人物：成年东亚女性，黑色长卷发，白皙肤色。

LOOK 1：
白色衬衫 + 黑色短裙
表情：无辜眼神

LOOK 2：
黑色吊带裙
表情：坏笑

每套单独输出完整提示词。
```

### B. 固定预设型

例如 `03 / 04 / 05 / 06 / 07`。

这些 Skill 已经内置完整 Look 或视觉模板。

你可以直接说：

```text
使用 Skill 07 的 OUTFIT 4。
人物替换为我上传的参考图。
保持婚纱结构不变。
把表情改成自然微笑。
输出 ChatGPT-Image 版提示词。
```

模型会优先复用 Skill 中已有结构，而不需要你重新写一遍完整提示词。

---

## 4. 如何使用 `{{变量}}`

部分 Skill 使用这种格式：

```text
{{人物参考图}}
{{服装}}
{{歌曲名}}
{{专辑封面}}
{{城市}}
{{街道}}
{{目的地}}
```

这些都是可以直接替换的变量。

例如 Skill 05 中原本写：

```text
城市：{{城市}}
区域：{{区域}}
目的地：{{目的地}}
```

你可以输入：

```text
城市：东京
区域：涩谷
目的地：Shibuya PARCO
```

不需要修改 Skill 文件本体。

---

## 5. 使用人物参考图

如果你上传了人物参考图，建议明确写：

```text
使用上传的人物参考图作为唯一人物参考。
严格保持脸型、五官比例、发型、发色、肤色、年龄感和整体辨识度一致。
只改变服装、姿势、表情和场景，不换人。
```

如果一个任务包含多张图，还可以补充：

```text
所有图片必须保持同一人物身份。
不要出现脸型漂移、发型变化、年龄变化或肤色变化。
```

---

## 6. 如何指定输出模型

同一个 Skill 可以根据模型改写语法。

你可以直接在任务末尾加：

```text
输出 ChatGPT-Image 版
```

或：

```text
输出 Midjourney 版
```

或：

```text
输出 Flux / SDXL 版
```

或：

```text
给我精简省 Token 版
```

Skill 会保留核心视觉规则，只调整提示词表达方式。

## 7. 完整使用示例：婚纱 Skill 07

假设你已经导入：

`skills/07-bilingual-wedding-lookbook-presets/SKILL.md`

然后上传一张人物参考图，只需要发送：

```text
使用 Skill 07。

使用上传的人物参考图作为唯一模特。
选择 OUTFIT 3｜开衩蕾丝鱼尾婚纱。
婚纱设计保持原预设不变。
表情改成：羞涩低头 / Shy Downcast Smile。

保持：
Front / Side / Back / Headshot 四宫格
纯白摄影棚
顶部中英文婚纱标题
中英文表情标签
真实蕾丝、刺绣、薄纱与拖尾细节

输出 ChatGPT-Image 可直接使用的完整中文提示词。
```

你不需要再次复制整套婚纱描述，Skill 已经知道 OUTFIT 3 的服装结构。

## 8. 一次生成多套 Look

如果想批量输出：

```text
使用 Skill 06。
把 OUTFIT 1—8 全部整理成独立提示词。
人物统一使用同一张参考图。
每套单独输出，不要合并。
全部使用 ChatGPT-Image 格式。
```

建议让模型“逐套独立输出”，而不是把 8 套服装写进一条提示词，否则容易发生服装混合。

## 9. 常用修改指令

### 只换人物

```text
保持所有服装、构图、标题和表情不变，只替换人物为新的参考图。
```

### 只换服装

```text
保持人物、背景、四栏排版和表情不变，只把服装替换为以下穿搭：……
```

### 只换表情

```text
服装和构图全部不变，大头贴表情替换为：委屈、眼眶湿润、嘴角轻微下垂。
```

### 去掉文字

```text
保持原有版式，只移除所有标题、编号和中英标签。
```

### 改背景

```text
保持人物和服装不变，把白色影棚替换为低饱和灰黑摄影棚。
```

## 10. 常见问题

### Q1：三视图衣服不一致怎么办？

追加：

```text
Front / Side / Back 必须是完全同一件服装。
严格保持领口、肩带、腰线、裙长、面料、鞋子、包袋和配饰一致。
禁止服装结构漂移。
```

### Q2：人物每一栏长得不一样？

追加：

```text
所有栏位必须是同一人物身份，不是相似人物。
保持脸型、五官比例、发型、发色、肤色和年龄感一致。
```

### Q3：文字容易乱码？

图像模型对复杂文字的稳定性不同。可以优先减少文字长度，例如：

```text
OUTFIT 01
Front
Side
Back
Headshot
```

如果重点是人物和服装，也可以先生成无文字版本，再后期排版。

### Q4：手部容易变形？

追加：

```text
natural hand anatomy, five fingers on each hand, no extra fingers, no fused fingers, no duplicated hands
```

### Q5：图太像拼图，不像杂志？

追加：

```text
premium editorial layout, balanced spacing, consistent margins, intentional magazine composition, unified typography, not a random collage
```

## 11. 推荐工作流

一个比较稳定的使用方式：

```text
人物参考图
↓
选择 Skill
↓
选择内置 Look / 输入新 Look
↓
确认表情
↓
指定输出模型
↓
生成完整提示词
↓
生图
↓
根据结果只修改一个变量
```

不要每次同时修改人物、服装、背景、构图、表情和镜头。一次只改一到两个变量，更容易保持稳定。

---

## 12. 如何新增自己的预设

你可以直接让模型：

```text
参考 Skill 06 的结构，新增 OUTFIT 09。
服装：……
表情：……
保持原有四栏、双语标题和质量规则。
```

如果确认好用，再把新的预设追加到对应 `SKILL.md`。

建议编号继续连续排列，方便长期维护。

---

## 13. 本仓库的核心原则

这些 Skill 的重点不是堆很多形容词，而是让视觉工作流变得稳定、可重复、可替换：

**人物统一 → 服装统一 → 构图统一 → 表情可控 → 变量可替换 → 输出可复用。**

当你发现某种提示词经常重复使用，就适合把它整理成新的 Skill。
